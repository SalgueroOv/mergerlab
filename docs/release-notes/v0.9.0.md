## Español

- Corrige 3 fallos que daban resultados incorrectos sin avisar: la columna de origen al apilar ahora funciona, el join ya no pierde filas si la clave tiene una celda vacía y se conservan los ceros a la izquierda (00123).
- Nueva opción «Leer todas las columnas como texto».
- Si el archivo de salida ya existe, la app pide confirmación antes de reemplazarlo.
- Más seguridad: el motor interno solo acepta peticiones de la propia app y la extensión del archivo de salida debe coincidir con el formato elegido.
- Excel con varias hojas: ahora puedes elegir una hoja concreta (por defecto se combinan todas).
- La app recuerda carpeta de destino, formato, separador CSV, modo y tipo de join.
- Al apilar, los enteros ya no pasan a decimales (1 → 1.0) cuando faltan en otros archivos, y se ignoran los espacios en los nombres de columna.
- Se leen los .xls que en realidad son HTML o texto, y hay un mensaje claro al superar el límite de filas de .xlsx.
- La ventana cabe en pantallas de 768 px.
- El aviso de actualización ahora muestra las novedades de cada versión.

## English

- Fixes 3 bugs that silently produced wrong results: the source-file column when stacking now works, joins no longer lose rows when the key has an empty cell, and leading zeros (00123) are preserved.
- New option “Read all columns as text”.
- If the output file already exists, the app asks for confirmation before replacing it.
- Better security: the internal engine only accepts requests from the app itself, and the output file extension must match the chosen format.
- Excel files with several sheets: you can now pick a specific sheet (all sheets are combined by default).
- The app remembers the destination folder, format, CSV separator, mode and join type.
- When stacking, integers no longer turn into decimals (1 → 1.0) when missing in other files, and spaces in column names are ignored.
- .xls files that are really HTML or text can now be read, and exceeding the .xlsx row limit shows a clear message.
- The window now fits 768 px-high screens.
- The update prompt now shows what's new in each version.
