## Español

- Nuevo botón «Vista previa»: muestra el resultado antes de guardarlo (filas y columnas, filas leídas y sin coincidencia por archivo, y las primeras 20 filas).
- Nuevos tipos de join «anti» para comparar listas: las filas de un archivo que no están en el otro.
- Nueva opción «Quitar filas duplicadas».
- Nueva opción «Incluir informe de la combinación»: una hoja extra en Excel/ODS, o un CSV aparte, con el resumen de lo que se hizo.
- Ayuda nueva con el botón «?» junto a las opciones, y recorrido de bienvenida actualizado.
- Corrige que, al guardar en .xls, algunos números enteros se guardaran como texto.

## English

- New “Preview” button: shows the result before saving it (rows and columns, rows read and unmatched per file, and the first 20 rows).
- New “anti” join types to compare lists: the rows of one file that are not in the other.
- New “Remove duplicate rows” option.
- New “Include merge report” option: an extra sheet in Excel/ODS, or a separate CSV, summarizing what was done.
- New help via the “?” button next to the options, and an updated welcome tour.
- Fixes some whole numbers being saved as text when saving to .xls.
